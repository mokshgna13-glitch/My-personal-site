# 🚀 MOKSHGNA — Personal Website

Welcome to my personal website! 🌌

This website is my digital space where I document my journey as a student, programmer, builder, robotics explorer, and future entrepreneur.

## 🌟 About the Project

This project was built as part of my journey with **Hack Club Treasure**.

The website includes:

- 🏠 A futuristic home page
- 👤 About Me section
- 🧠 Skills and learning journey
- 🏆 Achievements
- 📚 Education timeline
- 🌌 Interactive Project Universe
- 🤖 M-01 project dashboard
- 🗺️ Interactive Treasure Journey Map
- 🔐 Hidden Secret Mode
- ⚡ GOJO Easter Egg
- 📜 Build log
- 📱 Responsive design for mobile devices

## 🛠️ Built With

- **HTML5** — Website structure
- **CSS3** — Styling, animations, and responsive design
- **JavaScript** — Interactive features and effects

## ✨ Features

### 🌌 Project Universe

Projects are displayed like planets orbiting a featured project.

Clicking a project opens a detailed information panel.

### 🗺️ Treasure Journey

An interactive map that shows my journey from learning to building future projects.

### 🤖 M-01 Dashboard

A project dashboard showing the progress and mission of M-01.

### 🔐 Secret Mode

AI usage: I used AI for limited help with improving and organizing parts of the README. The website itself was built by me using HTML and custom CSS, with my own design choices and content.
